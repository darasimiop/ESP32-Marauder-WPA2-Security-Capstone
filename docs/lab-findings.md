# Lab findings and limitations

| Observation | What the project established |
| --- | --- |
| The device booted and exposed a working serial interface. | The firmware and basic device communication were operational. Functional test notes also record a successful access-point scan. |
| The device initially failed to recognize its microSD card. | The final report records a successful mount after solder rework. The troubleshooting notes show the value of testing the hardware and storage path before interpreting capture failures. |
| Early captures contained only part of the WPA2 authentication exchange. | Evidence collection needed verification before drawing conclusions from downstream analysis. The final report records a complete exchange in later lab testing. |
| The initial password assessment produced no match. A later assessment recovered the lab passphrase. | The initial result applied to the candidates tested. The later result demonstrated the risk of a guessable passphrase for this lab configuration. |

The outcome covers one authorized lab environment. The project records support a case study in hardware troubleshooting, packet analysis, and wireless authentication risk. The reported outcomes come from the project documentation and were reviewed as written.
